FNP Sales Analysis Dashboard
Project Overview
This project presents a sales analysis dashboard built in Microsoft
Excel. It summarizes sales performance through key performance
indicators (KPIs), revenue charts, product analysis, and order trends.
Dashboard Preview

Key Performance Indicators
The dashboard displays the following metrics:
- Total Orders: 1,000
- Total Revenue: ₹35,20,984.00
- Average Order-Delivery Time: 5.53
- Average Customer Spending: ₹3,520.98
Dashboard Features
- Revenue by occasion
- Revenue by product category
- Revenue by hour of order
- Monthly revenue analysis
- Top 5 products by revenue
- Top 10 cities by orders
- Occasion filter
- Order Date filter
- Delivery Date filter
Tools Used
- Microsoft Excel
- Data Analysis
- Data Visualization
- KPI Reporting
Key Observations
- Anniversary has the highest revenue among the occasions shown.
- Colors is the highest-revenue category among the categories shown.
- Monthly revenue varies across the year.
- The dashboard compares product revenue and order volumes across
  cities.
These observations are based on the dashboard visualization. Further
analysis of the underlying data may be needed to validate them and
understand the reasons behind the trends.
